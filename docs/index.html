Deckseed is an agent-first Markdown presentation generator. It combines Pandoc and Reveal.js to produce polished, self-contained HTML slides without making humans or models maintain generated markup.

Why Deckseed

A smaller AI authoring surface

Agents edit the approved Markdown and theme CSS. Pandoc generates the heavy runtime only at build time, reducing context use, duplication, and source drift.

Token-efficient source

One canonical content.md contains presentation metadata, approved copy, and slide structure.

Self-contained output

Reveal.js, CSS, and media are embedded into a single HTML file that works offline.

Freshness validation

A SHA-256 source stamp makes stale generated presentations a visible validation error.

Nine themes

Accessible dark, light, editorial, technical, and executive presets provide a practical starting point.

Private by default

Presentation sources and generated decks stay ignored, outside the repository's Git history.

Agent workflows

Shared skills define approval, scaffolding, theming, localization, preview, and validation behavior.

Frequently asked questions

Markdown slides without runtime maintenance

Can Pandoc generate a self-contained Reveal.js presentation?

Yes. Deckseed uses Pandoc's Reveal.js writer with standalone and embedded-resource options, then verifies that scripts, stylesheets, and media are embedded.

Why is Deckseed useful for AI coding agents?

The maintained inputs are compact Markdown and CSS. Generated runtime HTML stays outside the normal model context, which reduces token use and accidental edits.

Do generated presentations work offline?

Yes. Network access is needed while building the pinned Reveal.js runtime, but the resulting HTML presentation works without a server or network connection.

Does Deckseed require an AI service?

No. Deckseed is a local Pandoc and Node.js workflow. Its Agent Skills improve AI-assisted production, but the generator works without an AI provider.
